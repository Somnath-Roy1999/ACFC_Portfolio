ACFC E-Services India Pvt. Ltd. Website

Open index.html in any browser to preview the site.
To publish, upload index.html, styles.css, script.js and the assets folder to your web hosting provider.

To add directors' photographs later:
- Replace the .leader-placeholder blocks in index.html with <img> tags pointing to your images.
- Add CSS styling for the images, e.g. width:100%; height:250px; object-fit:cover.

The ATM image is an AI-generated illustrative image, not a verified photograph of a Hitachi ATM installation. Replace with an approved real photograph for production use.
The company logo is derived from the image supplied by the user.
The website uses Google Fonts; it will fall back to system fonts when offline.
The contact button opens the visitor's email app; no contact form backend is required.
